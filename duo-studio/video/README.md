# DUO STUDIO · kampagnevideo (9:16, 18,6 s)

Lavet i Remotion af de godkendte produkt- og modelbilleder. Tøjet er ikke AI-ændret.

- Redigér klip, tekster og tider i `src/Kampagne.tsx` (listen `SHOTS`, tider i beats).
- Forhåndsvisning: `npm install` og derefter `npm run dev`
- Render: `npm run render` → `out/duo-kampagne.mp4`
- På egen computer: kør med `DUO_CHROME=download npm run render` (bruger Remotions egen Chrome).
